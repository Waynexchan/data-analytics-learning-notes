# Data Analyst Knowledge Base

> A structured, beginner-friendly knowledge base for data analyst concepts, tools, reporting workflows, and interview preparation.

## 👋 Introduction

This repository documents my learning journey toward data analyst roles. It is organised as a professional GitHub portfolio knowledge base, with practical notes across SQL, Power BI, Excel, Python, Microsoft Fabric, Azure, Snowflake, data governance, reporting, and interview preparation.

Each topic is written to be:

| Principle | Description |
| --- | --- |
| Beginner-friendly | Concepts are explained in plain language with examples. |
| Business-focused | Notes connect technical skills to real analyst use cases. |
| Interview-ready | Each topic includes common interview questions. |
| Portfolio-ready | Markdown is structured, easy to scan, and organised by technology. |

## 🗺️ Learning Roadmap

| Stage | Focus Area | Goal |
| --- | --- | --- |
| 1 | Excel and reporting basics | Build confidence with spreadsheet analysis and KPI summaries. |
| 2 | SQL foundations | Query data, calculate KPIs, and explain business logic clearly. |
| 3 | Power BI and DAX | Build interactive dashboards and reusable measures. |
| 4 | Python analytics | Use Python for data cleaning, exploration, and automation. |
| 5 | Cloud and modern data platforms | Understand Fabric, Azure, and Snowflake concepts used in analytics teams. |
| 6 | Governance and communication | Learn data quality, documentation, definitions, and stakeholder reporting. |
| 7 | Interview preparation | Practise technical and business questions with clear examples. |

## 🧰 Technology Stack

| Area | Tools and Concepts |
| --- | --- |
| Querying | SQL, joins, CTEs, window functions, KPI logic |

| Reporting | KPI design, business observations, stakeholder communication |
