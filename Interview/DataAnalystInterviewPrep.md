# Data Analyst Interview Preparation

## 🧭 Overview

Data analyst interviews usually test technical skills, business thinking, communication, and problem-solving. Strong answers explain not only what tool or formula to use, but also why it fits the business question.

## 💼 Business Use Case

In an interview, a candidate may be asked to investigate why revenue dropped last month. A strong analyst would check data quality, compare time periods, segment by product or country, and explain findings clearly.

## 🔑 Key Concepts

| Area | What to Practise |
| --- | --- |
| SQL | Joins, aggregations, CTEs, window functions, KPI queries |
| Excel | Lookups, conditional formulas, Pivot Tables, reporting checks |
| Power BI | Measures, filter context, relationships, dashboard design |
| Business analysis | KPI definitions, trend analysis, segmentation |
| Communication | Explain assumptions, tradeoffs, and recommendations |
| Data quality | Missing values, duplicates, validation, reconciliation |

## 🧪 Example

Interview prompt:

> Revenue decreased by 12% last month. How would you investigate?

Structured answer:

1. Confirm the metric definition and data refresh date.
2. Compare revenue against previous month and same month last year.
3. Break revenue into order count and average order value.
4. Segment by country, product, customer type, and channel.
5. Check returns, cancelled orders, missing data, and unusual outliers.
6. Summarise the main driver and recommend the next analysis step.

## ❓ Interview Questions

| Question | Strong Answer Direction |
| --- | --- |
| Tell me about a data project you worked on. | Explain problem, data, tools, method, result, and business impact. |
| How do you validate your analysis? | Check totals, compare against source data, review filters, test edge cases, and document assumptions. |
| How would you explain SQL joins? | Joins combine rows from tables using related keys, with join type controlling which rows are kept. |
| What would you do if stakeholders disagree on a metric? | Align on definition, source, filters, grain, and ownership. |
| How do you communicate insights to non-technical users? | Use plain language, focus on business impact, and support conclusions with clear evidence. |
